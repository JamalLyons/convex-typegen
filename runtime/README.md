# convex-typegen-runtime

Runtime support for Rust bindings generated by `convex-typegen`. It provides the
typed client, model types, and Serde conversion for Convex values.

Apps use this crate as a normal dependency and use `convex-typegen` as a build
dependency. The runtime re-exports the `ConvexValue` derive from
`convex-typegen-macros`.

Follow the [convex-typegen website](https://jamallyons.github.io/convex-typegen/)
to set up your first project.
