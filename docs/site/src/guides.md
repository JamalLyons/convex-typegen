# Guides

These guides explain the crate split and build model, how to refresh a committed function spec, and
how to verify generated code against a local self-hosted Convex backend. The source pages remain in
`docs/guide/` so they can also be read directly in the repository.

Start with [concepts](docs/guide/concepts.md), the [getting started tutorial](docs/guide/getting-started.md),
or the [local testing guide](docs/e2e.md).
